KEYBOARD GUARD — американская раскладка вместо возвращающейся британской
Версия 1.0, Windows 10 / 11, для текущей учётной записи.

УСТАНОВКА
1. Распакуй ВЕСЬ архив в отдельную папку.
2. Дважды нажми INSTALL.cmd. Запускай от своего обычного пользователя.
3. Дождись надписи Installed. При необходимости выйди из учётной записи
   и войди снова, чтобы уже открытые приложения обновили список раскладок.

Администратор, Python, .NET SDK и доступ к интернету не нужны.

ЧТО ДЕЛАЕТ
— Убирает английский (Великобритания) из списка языков ввода.
— Убирает британскую и расширенную британскую клавиатуру из других языков.
— Для английского (США) оставляет обычную US QWERTY и делает её раскладкой
  по умолчанию. Русскую и прочие языки, кроме en-GB, сохраняет.
— Убирает британские записи из пользовательских Preload / Substitutes.
— Сохраняет текущий язык интерфейса, если он британский английский.
— Добавляет ярлык в автозагрузку текущего пользователя. После входа
  в Windows проверяет настройки каждые 10 секунд в течение двух минут,
  затем завершает работу. Постоянного фонового процесса нет.
— Перед первым изменением сохраняет резервную копию. Повторная установка
  не перезаписывает исходную копию.

КНОПКИ
INSTALL.cmd  — установить и включить исправление после входа в Windows.
REPAIR.cmd   — исправить раскладки один раз.
STATUS.cmd   — показать текущие языки, раскладки и состояние автозапуска.
REMOVE.cmd   — выключить автозапуск; оставить текущие раскладки и копию.
RESTORE.cmd  — выключить автозапуск и вернуть настройки из исходной копии.

ОГРАНИЧЕНИЯ
Это утилита исправления настроек, а не драйвер клавиатуры. Она не запрещает
Windows, синхронизации или программам добавлять раскладки в дальнейшем.
Если британская появляется позднее двух минут после входа, запусти REPAIR.cmd.
Уже открытые приложения иногда хранят старый список до следующего входа.
Экран входа и настройки других учётных записей она не меняет.
Если автозагрузка приложений заблокирована политиками организации,
исправление при входе работать не будет.

ФАЙЛЫ
Установленная копия и журнал:
%LOCALAPPDATA%\Emrikh\KeyboardGuard
Исходная резервная копия: before-install.json
Журнал: guard.log
REMOVE.cmd оставляет эти файлы для возможного восстановления.

Запуск используется со встроенным Windows PowerShell 5.1.
ExecutionPolicy Bypass применяется только к запускаемому процессу;
системная политика выполнения скриптов не меняется.
Исходный код приложен. Утилита не читает нажатия клавиш и не отправляет
данные в интернет. Изменения касаются настроек ввода текущего пользователя
и её собственного ярлыка автозагрузки.

ПРОВЕРКА БЕЗ ИЗМЕНЕНИЙ
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\KeyboardGuard.ps1 -Mode Preview
